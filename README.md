# underGroundRocket

지하로켓 구하기 - 이도겸

## 게임 기획서

### 스토리
땅을 향해 발사된 지하로켓을 찾기 위해, 플레이어가 지하로 내려가며 탐색한다.

### 핵심 플레이 루프
시작 → 행동(좌/우 이동) → 미션 수행 → 보상 획득

### 비주얼/연출
- 시점: 3인칭 사이드뷰
- 그림체: 픽셀 아트
- 배경: 흙
- 배경색: 흙색 계열
- 메인 캐릭터: 졸라맨
- 장애물: 지렁이

### 게임 진행 방식 및 규칙
1. 플레이어 조작 방식
   - 스페이스바: 시작
   - 왼쪽 이동: ← 방향키 또는 `A`
   - 오른쪽 이동: → 방향키 또는 `D`
2. 시작 후 메인 캐릭터는 일정한 속도로 아래로 떨어진다.
3. 메인 캐릭터가 장애물(지렁이)에 닿으면 해당 구간 진행이 종료된다.
