# 지하로켓 구하기

**만든 사람:** 이도겸
**반:** 프로잭트
**기획서 작성일:** 2026-10-24 ~ 2026-10-31
**기획 상태:** 웹 게임 구현 완료 · GitHub Pages 배포 설정 포함

## 게임 플레이

- `index.html`을 브라우저에서 열거나 GitHub Pages 배포 주소에서 플레이할 수 있어요.
- 왼쪽/오른쪽 방향키 또는 `A`/`D` 키로 사람을 좌우로 움직여요. 휴대폰에서는 화면 아래쪽 화살표 버튼을 눌러요.
- 지렁이에 닿으면 게임이 끝나요. 생존 시간 1초마다 1,000점이 올라가요.
- 게임 중 원형 미션 버튼이 나타나면 10초 안에 누르세요. 성공하면 3초 동안 점수가 1.5배가 돼요. `Space` 키로도 미션을 완료할 수 있어요.
- 최고 기록은 현재 브라우저에 저장돼요.

## GitHub Pages 배포

`.github/workflows/deploy-pages.yml`은 `main` 브랜치에 반영될 때 게임을 자동으로 배포해요. 저장소의 **Settings → Pages → Build and deployment**에서 배포 원본을 **GitHub Actions**로 설정하고, Actions에서 **Deploy game to GitHub Pages** 실행이 성공하면 `https://haedaledu.github.io/underGroundRocket/`에서 플레이할 수 있어요.

## STEP 1. 무엇을 만들까요?

### 작품 소개

- **작품 이름:** 지하로켓 구하기
- **한 줄 소개:** 지하에서 지렁이 장애물을 피해 사람이 최대한 오래 살아남는 간단하고 중독성 있는 게임이에요.
- **만들고 싶은 이유:** 크롬 공룡 게임처럼 규칙은 단순하지만 계속 도전하고 싶어지는 게임을 만들고 싶어요.
- **누가 플레이하나요?:** 짧은 시간 동안 간단한 게임을 즐기고 싶은 사람 누구나 플레이할 수 있어요.

### 게임의 기본 흐름

1. 게임을 시작하면 사람이 지하로 내려가요.
2. 플레이어는 사람을 좌우로 움직여 지렁이 장애물을 피해요.
3. 오래 살아남을수록 점수가 올라가요.
4. 가끔 나타나는 원형 버튼 미션에 제한 시간 안에 성공하면 잠시 점수 보너스를 받아요.
5. 지렁이와 부딪히면 게임이 끝나고 최종 점수를 보여 줘요.

## STEP 2. 언제 완성일까요?

### 꼭 있어야 하는 기능

1. **생존 시간 점수:** 살아 있는 동안 시간이 지나면 점수가 올라가요.
2. **부드러운 이동:** 사람의 X좌표를 조작해 좌우로 부드럽고 빠르게 움직일 수 있어요.
3. **장애물과 충돌:** 지렁이 장애물을 피하고, 부딪히면 게임이 끝나요.
4. **원형 버튼 미션:** 화면에 원형 버튼 미션이 나타나면 10초 안에 눌러야 해요.
5. **미션 성공 보너스:** 미션을 성공하면 그 뒤 3초 동안 점수가 1.5배로 올라가요.
6. **게임 종료와 점수 표시:** 게임이 끝나면 최종 점수를 확인하고 다시 시작할 수 있어요.

### 이렇게 되면 완성

- [x] 게임을 시작하고 끝낼 수 있으며, 게임이 끝난 뒤 최종 점수가 보여요.
- [x] 생존 시간이 1초 늘어날 때마다 점수가 1,000점 올라요. *(1ms마다 1점과 같은 속도예요.)*
- [x] 키보드와 터치 조작에 따라 사람의 X좌표가 끊기지 않고 부드럽게 바뀌어요.
- [x] 지렁이와 부딪히면 게임이 끝나고, 피하면 계속 플레이할 수 있어요.
- [x] 원형 버튼 미션에 10초 제한 시간이 표시되고, 시간이 끝나면 미션이 종료돼요.
- [x] 미션 성공 직후부터 3초 동안 점수가 1.5배로 계산되고, 3초가 지나면 원래 점수로 돌아와요.
- [x] 미션에 실패해도 게임은 계속돼요. *(임시 결정: 실패 페널티 없음.)*

## STEP 3. 어떻게 생겼을까요?

### 화면 구성 제안

- **게임 화면:** 지하를 배경으로 사람과 지렁이 장애물이 보여요.
- **점수 표시:** 화면 위쪽에 현재 점수가 보여요.
- **미션 표시:** 미션이 시작되면 원형 버튼과 남은 시간이 보여요.
- **보너스 표시:** 1.5배 점수가 적용되는 동안 남은 시간을 알려 줘요.
- **게임 종료 화면:** 최종 점수와 다시 시작 버튼이 보여요.

### 조작 방법 제안

- 왼쪽/오른쪽 방향키로 사람을 좌우로 움직여요.
- 버튼을 누르고 있는 동안 움직이고, 손을 떼면 이동을 멈춰요.
- **임시 결정:** 첫 버전은 키보드 조작을 기준으로 만들어요.

## STEP 4. 어떤 순서로 만들까요?

1. 게임 화면과 사람의 좌우 이동을 만들어요.
2. 생존 시간에 따라 점수가 오르게 해요.
3. 지렁이 장애물을 만들고 충돌 및 게임 종료를 연결해요.
4. 원형 버튼 미션, 10초 제한 시간, 미션 성공 판정을 만들어요.
5. 성공 후 3초간 적용되는 1.5배 점수 보너스를 만들어요.
6. 점수·미션·게임 종료 화면을 정리하고 직접 플레이하며 속도와 난이도를 조정해요.

- 사람의 이동 속도와 게임이 점점 어려워지는 정도
- 미션이 나타나는 간격과 미션 성공 판정 방법
